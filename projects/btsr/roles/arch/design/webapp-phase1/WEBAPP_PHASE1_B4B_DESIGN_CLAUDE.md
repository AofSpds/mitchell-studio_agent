## 0. 지금

- 주소는 `http://` 둘 — 가게 와이파이의 맥 이름 주소와 Tailscale 주소(`<맥>.<tailnet>.ts.net:8765`). 둘 다 https가 아님 → 아이폰 홈 화면 웹앱 알림(Web Push)과 사진 앱으로 바로 보내기(파일 공유)가 안 됨(둘 다 보안 연결에서만).
- 서버는 사설망 · 이 맥 · Tailscale 주소만 받고(`allowed_ip`), PIN 잠금은 **접속한 IP마다** 센다. 쿠키에 `Secure`가 없다.
- 서버는 파이썬 표준 라이브러리만 쓴다.

## 1. 한 줄

https는 **맥의 Tailscale이 맡고**(`tailscale serve` — tailnet 안에서만, 인증서도 Tailscale이 갱신) 웹앱 서버는 지금처럼 맥 안에서 http로 듣는다. 알림은 **표준 Web Push**로, 서버가 4-a의 사건 가운데 셋에서 보낸다.

## 2. https의 길 — `tailscale serve` [안, 권고]

| 길 | 어떻게 | 좋은 점 | 나쁜 점 |
|---|---|---|---|
| **ㄱ `tailscale serve` (권고)** | 맥에서 한 번 `tailscale serve --bg 8765` → `https://<맥>.<tailnet>.ts.net` 이 맥 안 `127.0.0.1:8765`로 | 인증서 받기 · 갱신을 Tailscale이 함. 서버 코드에 TLS 없음. tailnet 밖에서는 안 열림(serve는 tailnet 안만) | 서버가 보는 접속 주소가 모두 `127.0.0.1` → 3번에서 고침 |
| ㄴ `tailscale cert` + 서버가 TLS | 인증서 파일을 받아 `ssl`로 직접 | 서버가 접속 주소를 그대로 봄 | 90일마다 갱신을 우리가 돌려야 함 · 인증서 파일이 맥 디스크에 · 코드 늘어남 |

- 두 길 모두 tailnet 관리 화면에서 **HTTPS 인증서 켜기**가 들고, 그때 맥 이름 · tailnet 이름이 공개 인증서 장부(CT)에 남는다 — 결정 05가 알고 정한 것.
- 가게 와이파이의 `http://` 맥 이름 주소는 **그대로 둔다**(Tailscale이 꺼졌을 때 보내기만이라도 되게). 다만 알림 · 사진 앱 보내기는 https 주소에서만 → 홈 화면 아이콘은 https 주소로 다시 만든다(한 장 3번).
- **Funnel(인터넷 공개)은 쓰지 않는다** — 나-3. 한 장의 '하지 말 것' 첫 줄.

## 3. 서버가 고칠 것 — 프록시 뒤에서 (R4.5)

- **누가 들어왔나**: 접속이 `127.0.0.1` · `::1`에서 왔고 `X-Forwarded-For`가 있으면 그 **마지막 값**을 손님 주소로 보고 `allowed_ip`를 그 주소로 다시 본다. 이 맥 밖에서 온 접속의 `X-Forwarded-For`는 믿지 않는다(지금처럼 접속 주소만). → 잘못해서 Funnel이 켜져도 인터넷 주소는 막힌다(이중 안전).
- `Tailscale-Funnel-Request` 머리글이 있으면 403 [맥에서 확인 — 머리글 이름].
- **PIN 잠금**은 위에서 고른 손님 주소로 센다(지금대로면 프록시 뒤 모든 휴대폰이 한 주소로 묶여 한 대가 틀리면 다 잠김).
- **쿠키**: https로 온 요청(`X-Forwarded-Proto: https`)이면 `Secure`를 붙인다. http 주소의 쿠키와 https 주소의 쿠키는 다른 것 — 주소마다 PIN을 한 번씩 넣는 것은 정상(한 장에 적음).
- 서버가 켜질 때 찍는 주소에 `https://<맥>.<tailnet>.ts.net`을 더한다(`tailscale serve status`가 켜져 있을 때만).

## 4. 알림 — Web Push (R4.4)

### 4-1. 화면 (2판 — 결정 25: 알림 설명 · 안내 화면 · 카드 없음)

- `static/sw.js`(서비스 워커)를 둔다 — 알림을 받아 보이고, 누르면 Jobs(지금 한 편 — 4-a 2판)를 연다. `manifest.webmanifest`는 지금 것에 `display: standalone`이 있는지 확인하고 없으면 더함.
- **켜는 곳은 Manual 탭 한 곳**: 「알림 켜기」 · 「알림 끄기」 · 「시험 알림」 단추(누를 때만 허락 창 — 아이폰은 사람이 누른 뒤에만 물음)와 켜는 법 몇 줄(한 장 3번의 휴대폰 쪽을 Manual 글로). 다른 탭 · 첫 화면에 카드 · 띠 없음.
- 켤 수 없는 곳(http 주소 · 홈 화면 아님 · `cryptography` 없음)에서는 Manual의 「알림 켜기」가 흐려진다 — 풀이 글은 두지 않음(R1.7). 까닭은 Manual 켜는 법 글에 이미 있음.

### 4-2. 서버

- 알릴 일 (결정 33 — [안] 그대로 정해짐): **확인해 주세요**(`events` kind `check`) · **다 됐어요**(마지막 뽑기 `done`) · **문제가 생겼어요**(`stop`이고 미첼이 할 것이 있음). 같은 작업 같은 일은 10분 안에 한 번.
- 알림 글에 **손님 정보 · 작업 제목 · 가게 이름을 넣지 않는다** — 잠긴 화면에 보이므로. 글 = 위 셋 가운데 하나 + 단계 이름(예: "확인해 주세요 — 원고"). 열 작업은 id로만.
- 받는 곳(구독)은 데이터 폴더 `push/subs.json`(git 밖). 410 · 404가 오면 그 구독을 지움.
- 보내기: VAPID(ES256 서명) + 내용 암호화(aes128gcm, RFC 8291)를 **`cryptography` 한 라이브러리**로 직접(약 100줄). `pywebpush`는 `requests` 등 딸린 것이 많아 쓰지 않는다 [안]. 보내는 곳은 휴대폰이 정한 애플 알림 서버(바깥으로 나가는 연결 — 들어오는 문은 열지 않음).
- **VAPID 개인 키**는 처음 켤 때 데이터 폴더 `push/vapid_private.pem`에 만들고(권한 600) git · 기록 · 화면 어디에도 쓰지 않는다(AGENTS.md 5). 공개 키만 화면에 준다.
- `cryptography`가 없으면 서버는 그대로 돌고 알림만 꺼진다 — Manual의 「알림 켜기」가 흐려짐, 서버 시작 글에 깔 명령 한 줄.
- 끝점: `GET /api/push/key` · `POST /api/push/subscribe` · `POST /api/push/unsubscribe` · `POST /api/push/test`(Manual의 「시험 알림」) — 모두 PIN 쿠키.

## 5. 받아들임 기준 (PMO 요청에 옮길 것)

1. `127.0.0.1`에서 온 요청이 `X-Forwarded-For: <인터넷 주소>`를 달면 403, `<Tailscale 주소>`면 통과. 바깥 주소에서 온 요청의 `X-Forwarded-For`는 무시.
2. 프록시 뒤 두 손님 주소 — 한 주소가 5번 틀려도 다른 주소는 잠기지 않음.
3. `X-Forwarded-Proto: https`이면 쿠키에 `Secure`.
4. RFC 8291 부록 A의 시험 값으로 암호화 결과가 같음(바깥 연결 없이). VAPID JWT를 공개 키로 검증해 통과.
5. 가짜 알림 서버(시험 안의 작은 http 서버)로: `check` 사건 → 알림 하나 · 같은 것 10분 안에 다시 → 안 감 · 410 → 구독 지워짐.
6. 알림 글에 작업 제목 · 손님 정보가 없음(시험 작업 제목에 표시 글자를 넣고 알림 본문에 없는지).
7. 개인 키 파일이 저장소 안에 생기지 않음(`git status` 깨끗) · 기록에 키 값 없음.
8. `cryptography`가 없을 때 서버가 켜지고 알림 끝점은 "준비 안 됨"을 답함.
9. 시험 전부 — 저장소 전부를 풀어 환경 값 없이 OK. `cryptography`가 없는 곳에서는 4 · 5를 건너뛰되 건너뛴 수를 반환서에 적음(ARCH는 대조 때 따로 깐 곳에서 다시 돌림).
10. [맥에서 확인] 한 장의 1–4를 한 뒤 아이폰(Tailscale 켬, LTE)에서: https 주소가 경고 없이 열림 · Manual 탭에서 알림 켬 · 앱을 닫고 시험 작업을 `check`로 → 열기 전에 알림 옴(R4.4) · 가게 와이파이에서 Tailscale을 끄면 https 주소는 안 열림(R4.5). 결과는 1차 끝 맥 시험 기록에.

## 6. 하지 않는 것

- Funnel · 공유기 포트 열기 · 인터넷 공개 · 알림 종류 늘리기 · 잘게 고르기 · 이메일 · 문자. 사진 앱으로 바로 보내기(파일 공유)는 https만 깔고 화면은 묶음 6(R6.5와 함께).
