## 물음 2 — 알림을 위해 맥에 하나 깔기

알림을 보내려면 맥의 기본 파이썬에 `cryptography`(암호화 도구) **하나**를 깔아야 합니다. 맥 시험 때 한 장의 명령 한 줄로 까시게 됩니다(`/usr/bin/python3 -m pip install --user cryptography`). 지금 웹앱은 따로 까는 것이 하나도 없습니다.

1. **깖 (권고)** — 하나뿐이고 널리 쓰는 것. 없거나 깔다 실패해도 웹앱은 그대로 돌고 알림만 꺼짐
