## 4. 남은 것

1차 끝 맥 시험에서 실제 r2 첫 프로젝트의 캔버스가 1080×1920인지 확인한다. CapCut 음악 목록의 ‘상업적 이용’ 표시도 그때 확인하고 없으면 PLN에 알린다. 실제 사진에서의 얼굴 분류와 실제 작성자가 만든 원고 품질은 이번 윈도 시험에서 판정하지 않았다.

## 5. 배운 것

흐린 사진을 빼거나 소재의 종류를 다시 고르면 얼굴을 만들 수 있는지도 달라진다. 답을 저장한 뒤 현재 접수 표로 다음 물음을 다시 계산해야 화면 17이 맞는 때에 나온다.
