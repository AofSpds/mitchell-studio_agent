## 최종 반환 · 덧붙임 2·3

### 1. 결과

제품 원격 `feat/webapp-mac-test-doc-add2b-20261121`의 최종 머리는 `e095396`이다. 기준은 제품 main `9a41aa6`이며 ARCH 요청서 `4964f37`·`ae0792d`를 반영했다. 재시작 질문에는 덧붙임 3의 정정이 적용된다.

### 2. 증거

- 이전 기능 가지가 원격에 올라 있어 새 가지를 사용했다. `git range-diff`에서 `77312f1 → 68bb724`, `18f56eb → d443d49`가 각각 같은 패치였다. 두 커밋을 옮긴 직후 맥 테스트 글 본문도 이전 머리와 일치했다.
- `git merge-base --is-ancestor 9a41aa6 e095396`와 `git diff --check`가 통과했다. 바탕 대비 차이는 `app/webapp/MAC_RUN_PHASE1.md` 한 파일, 62줄 추가·30줄 삭제다. [제품 diff](https://github.com/AofSpds/mitchell-studio/compare/9a41aa6ba787e0381f826bd60fc702759602dff7...e0953961feb4f0039c47e09f95ccdb71fedc1887)
- 임시 Git 저장소에서 HEAD가 달라도 `agents/`만 바뀌면 비교 결과는 0, `app/`와 `templates/`를 각각 바꾸면 1임을 확인했다. stash와 충돌할 수 있는 새 커밋·미커밋 수정도 만들어 파일 목록과 현재 내용의 차이를 읽었다. 대조 뒤에도 작업 파일과 stash SHA가 보존됐다.
- 38개 회차 걸음 중 변경된 행은 2-1·3-1이다. 3-3~3-5 원문과 17개 셸 블록은 `18f56eb`와 일치한다.

최종 `e095396`의 저장소 전체를 각 환경별로 `git archive`해 `PYTHONUTF8`·`PYTHONIOENCODING`·`PYTHONPATH`를 해제한 뒤 Python 3.13.14에서 전체 회귀를 실행했다.
