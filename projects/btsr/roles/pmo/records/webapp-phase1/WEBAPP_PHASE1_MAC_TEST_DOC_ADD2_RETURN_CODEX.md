## 4. 남은 것

ARCH 대조와 RSCH의 main 반영이 남았다. 맥에서 진행 중인 1회차에는 접속하지 않았다. 실제 화면 유지와 서비스 재기동은 맥에서 해당 절차를 사용할 때 확인한다.

## 5. 배운 것
