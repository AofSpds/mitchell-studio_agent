### 검증 기록

- Windows · Python 3.13.14. 최종 문서와 기준 코드·시험을 함께 담은 `28e779e`로 환경마다 전체 저장소를 새로 풀었다. 명령은 `git archive --format=zip -o <임시>/source.zip 28e779e` 뒤 압축을 푼 최상위에서 `python -m unittest discover -s app/webapp/tests -v`. `PYTHONUTF8`·`PYTHONIOENCODING`·`PYTHONPATH`를 제거했다. `tests/_env.py`가 외부 임시 데이터·설정과 `WEBAPP_DEV_PUSH=0`, `WEBAPP_RUNNER=0`, `WEBAPP_TICK_SECONDS=0`을 설정했다. 두 최종 실행은 순서대로 돌렸다. 제품 코드·시험은 `94d4522`와 같다.
- 기본 Python은 135개 중 133개 통과·암호화 시험 2개 건너뜀(93.691초). 외부 가상환경 `webapp-test-b4b-venv`의 `cryptography 50.0.2`에서는 135개 모두 통과했다(125.239초). 실행 원출력은 이 PC의 `%TEMP%\btsr-014-final-default-wdjuknu7\tests.log`와 `%TEMP%\btsr-014-final-crypto-cydo9ox7\tests.log`다.
- 첫 문서 `73b09f9`의 회귀에서 `test_one_job.Screen.test_mac_run_question_1`이 결정 15 원본 파일명 누락을 찾아 명시했다. 첫 병렬 실행의 기본 환경에서 로컬 HTTP 연결 종료 1건·임시 `status.json` 교체 권한 오류 1건도 있었다. 제품 코드와 시험은 바꾸지 않았다.
- 문서 정적 검사에서 회차별 15+13+10, 모든 걸음의 다섯 칸과 결과 줄 번호, 화면 사용 8곳의 기다림 문구, 덧붙임 2의 표와 원문 일치를 확인했다. 셸 블록 17개의 Bash 공통 문법(`bash -n`)과 내부 Python 예제 5개(`ast.parse`)를 검사했다.
- 제품과 별도인 임시 로컬 Git 원격에서 글에 수록한 결과 명령으로 새 결과 가지, 세 회차 누적, 같은 회차 재실행 시 중복 커밋 없음, 결과 한 파일, 작성자·커미터 일반값, 미검토 파일이 있는 폴더에서 중단을 확인했다. 새 판·복구 명령도 두 임시 사본에서 확인했다. 작업자 파일이 같으면 로컬 값을 되씌우고 시작 가지·SHA로 돌아갔다. 원격에서 그 파일을 바꾼 경우 외부 원본을 보존하고 되씌우기 전에 멈췄다. 이 시험의 서비스 재기동은 대역을 썼다.

## 3. 바뀐 것

`git diff --numstat 94d4522 28e779e`은 `387 / 66 app/webapp/MAC_RUN_PHASE1.md` 한 줄이다. 문서 커밋 `73b09f9`·`28e779e`를 별도 기능 가지에 두었다. 제품 코드·시험·템플릿 차이는 0이다. S1의 제품 대조 범위는 `c9c99c4`의 개설 패킷이다. PRIMARY는 `94d4522`에서 해당 줄을 다시 읽고 화면·설정·자료 경계에 관한 메모를 수용했다. 보조는 제품 편집과 맥 실행 없이 읽기만 했고 서로 겹친 변경은 없었다.

## 4. 남은 것

- 실제 맥 작업자의 명령·화면 공유, CLI 값, CapCut·ChatGPT 앱, 실제 설치의 TLS·키 권한·알림·저장은 세 회차에서 확인한다. 화면 충돌이나 사용 중인 서비스의 설정 불일치는 해당 걸음에서 기록한다.
- 받은 소재로 1-8을 하기 전, 맥의 실제 접수 CLI가 허용된 두 경우 외에 원본을 외부로 전송하는지 확인해야 한다. 제품 `runner.py:40,438`과 `prompts/intake.md:7`은 소재 폴더 읽기를 지시한다. Windows 코드 대조로 해당 맥의 추론 서비스 처리 위치까지 증명할 수 없어, 확인 전에는 실제 자료를 보내지 않도록 적었다.
- 결과 원격과 제품 main을 다루는 맥 동작은 절차로만 작성했다. 합치기 판단은 IVA 판정 뒤 RSCH가 맡는다.

## 5. 배운 것

서비스 설정을 바꿔도 실행 중인 Python은 이미 읽은 모델과 암호화 모듈을 계속 쓴다. 재기동 시점을 설정·라이브러리 확인 뒤에 두었다. 개발자 글은 보류한 항목 한 편만 남기는 기능이 없어, 한 편이라도 미검토면 전송 스위치를 꺼 두어야 한다.
