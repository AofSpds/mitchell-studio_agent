# 미첼 스튜디오 웹앱 — 요구사항 수집을 위한 지금 상태 정리 (2026-11-19 기준)

## 1. 한 줄 요약

- **무엇:** 미용실 운영자가 시술 사진·영상을 휴대폰 웹앱으로 보내면, 맥 한 대에서 역할별 AI 세션들이 인스타 릴스(세로 영상 약 14초)를 만들어 주는 개인용 자동화 작업 공간입니다.
- **한알이 말한 이 웹앱의 뜻:** "같은 작업을 반복하는 사용자에게 같은 작업을 하지 않도록 하는 자동화 개인 웹앱입니다."
- **지금의 가장 큰 어긋남:** 사진·영상을 올려도 아무 일도 시작되지 않습니다. 사용자가 웹앱 밖(다른 앱)으로 네 번 나가서 말하거나 눌러야 작업물이 나옵니다.
- **가려는 곳:** 올리면 끝까지 저절로 가고, 사용자는 웹앱 안에서 진행과 작업물을 봅니다.

- 고정값: 내보내기 MP4 · 1080×1920 · 30fps.
- ⑥에서 '카드'는 컴퓨터 유즈에게 주는 작은 작업 지시서입니다. 6.1 Terra가 길게 버티지 못해 일을 잘게 나눈 것입니다.
- ⑥은 ChatGPT 사용량이 끝나면 다음 날 오전 7시까지 멈춥니다.

### 올린 뒤 작업물이 나오기까지 웹앱 밖으로 나가는 네 번

1. 올리기 전에 ChatGPT에서 AI 얼굴 사진을 받음
2. 올린 뒤 Claude 앱에 "업로드 확인"이라고 말함
3. 맥 Codex 앱에서 ⑥을 시작하고 카드 사이를 이어 줌
4. 다섯 곳 앱에 직접 올림

「고칠 점」을 적은 뒤에도 Claude 앱에 "작업 확인"이라고 말해야 해서, 고칠 때마다 한 번 더 나갑니다.

## 4. 웹앱의 지금 모습

### 4-1. 화면

- 뼈대: 위에 로고, 아래에 탭 넷 **Send · Jobs · Post · Manual**. 이름표(탭·제목·큰 단추)는 영어, 설명은 한국어. 가게다운 갈색 계열.
- 기술: 파이썬 기본 기능만으로 만든 서버(추가 설치 없음) + 화면 파일 하나. PIN 6자리로 들어감(30일 기억). 같은 와이파이·그 맥·Tailscale 주소에서만 열림. 주소는 http.

| 화면 | 있는 것 |
|---|---|
| Send | 큰 「Send」 단추(사진·영상 고르기) · 요청 글 칸(안 적어도 됨) · 「Options」 |
| Jobs | 「⚙ 기본 옵션」 · 작업 카드 목록 · 작업을 누르면 8단계가 세로로(이름·누가·상태·시각) · 끝난 단계마다 「산출물 보기」 · 확인 단계에 「좋아요」/「고칠 점 적기」 |
| Post | 승인한 작업마다: 영상 · 「영상 저장」 · 다섯 곳 캡션 · 「캡션 복사」 · 「올림」 |
| Manual | 흐름 설명 · 날마다 할 일 · 상태 · **Helpdesk**(문제 다섯 가지 가운데 고르면 상황 글을 만들어 복사하고 Claude/ChatGPT 앱을 엶) |

### 4-2. 웹앱이 하는 일과 하지 않는 일

- 웹앱은 지금 **보내는 문 · 진행을 보는 창 · 확인 단추 · 캡션 복사판**입니다. 일 자체는 맥의 Claude 세션들과 컴퓨터 유즈가 합니다.
- Send를 누르면 맥의 받는 폴더에 파일이 들어가고 **거기서 멈춥니다.** 웹앱은 작업을 만들지 않습니다. Claude가 "업로드 확인"을 들어야 작업이 생기고 Jobs에 카드가 뜹니다.
- 「좋아요」·「승인」은 상태만 바꿉니다. 다음 일을 시작시키지 않고, Claude 세션이 켜져 있다가 상태를 봐야 이어집니다.
- 서버가 스스로 하는 일은 셋입니다: ⑥에서 결과를 보고 다음 카드 내기 · 목소리 간격 맞추기 · 완성 영상을 알아채고 검사하기(크기·소리·목소리 겹침).
- 화면은 20초마다 다시 읽습니다. 서버가 화면으로 바로 밀어 주는 길은 없습니다. 다 됐다는 알림은 웹앱이 아니라 Claude 대화창으로 갑니다(기획서: "따로 알림 기능은 만들지 않음").

### 4-4. 설정(옵션) 전부

| 옵션 | 기본값 | 고를 수 있는 것 |
|---|---|---|
| 목소리 | ChatGPT가 알맞게 고름 | 캡컷 목소리 이름 다섯(차분한 언니 · 따뜻한 친구 · 건방진 깡패 · 링 아나운서 · 한국 남자) · 이름 직접 적기 |
| 목소리 속도 | 1.5배 | 1.0 · 1.3 · 1.5 · 1.6 |
| 음악 | ChatGPT가 알맞게 고름 | 기존 3곡 번갈아 · 곡 이름 3개 · 직접 적기 |
| 끝 문구(예약 안내 + 가게 이름) | 켬 | 켬 · 끔 |
| 길이 | 14초 | 12 · 14 · 15초 (원고 글자 상한 75 · 85 · 90) |
| 원고 확인 | 켬 | 켬 · 끔 |
| 미리보기 확인 | 켬 | 켬 · 끔 (아직 쓰이지 않음) |
| 올릴 곳 | 다섯 곳 모두 | 인스타만 · 인스타·유튜브·틱톡 · 인스타·네이버·당근 |
| AI 얼굴 표시 | 항상 | 바꿀 수 없음 |

- 세 층으로 겹칩니다: 기본 옵션 ← 보낼 때 바꾼 것 ← 작업에서 바꾼 것.
- **설정이 없는 것:** 글자 모양(글꼴·크기·위치·테두리 — 본보기 프로젝트를 복제) · 장면 순서와 길이(Claude가 장면표를 씀) · 고정 글자 문구 · 가게 이름과 예약 문구(코드에 있음) · 캡션 말투와 해시태그(uploader 지침에 있음) · 원고의 말투와 흐름 · 모델 연령.
- 그래서 설정은 지금 **소리와 길이** 쪽에만 있습니다.

### 4-5. 요구사항을 적을 수 있는 자리

| 지금 있는 것 | 남는 곳 | 한계 |

## 9. 아직 정해지지 않은 것 — 요구사항으로 물어야 할 것
