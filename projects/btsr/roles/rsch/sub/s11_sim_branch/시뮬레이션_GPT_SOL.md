# S11 갈림길 · 영상 제작 모의 실행

1. 시술 전 사진만 묻는 화면 4까지 가려면 접수의 추가 질문을 줄여야 합니다. 「이대로 만들기」를 고르면 현행 지시로도 시술 전 장면과 표시 없이 원고와 장면표를 만들 수 있습니다.
2. 얼굴 생성 실패 두 번과 미첼이 누르는 재제작 한도 3회는 별개입니다. 개발자에게 넘어간 뒤 같은 자료로 「처음부터 시작」하는 길은 현행 코드에서 찾지 못했습니다.
3. 현행 웹앱은 720×1280 영상을 경고와 함께 승인할 수 있고, 완성본 수정 글은 저장만 합니다. 규격 판정이 승인·저장·재내보내기를 제어하고, 수정 글을 받으면 편집을 시작해야 v1 → v2 → v3이 이어집니다.

제품 `origin/main`의 로컬 사본 `3072e7e`에서 글과 코드를 대조했습니다. 웹앱 목표는 요청서 14–16번, 화면은 시안 3판입니다. 가짜 입력은 세로 영상 9초 한 개, 시술 후 사진 두 개, Request 「레이어드 컷」, 기본 Options입니다. 영상도 시술 후 장면이라는 가정이며, 영상·사진·프로젝트 파일의 판정은 아래에서 가정으로 표시했습니다.
