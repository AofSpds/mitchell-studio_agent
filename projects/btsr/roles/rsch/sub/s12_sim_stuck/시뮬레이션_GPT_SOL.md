# 영상 제작 모의시험 — 막힘과 다시 시작

흐린 사진을 뺄 수는 있지만, 현재 제품은 흐림을 묻거나 해당 사진만 다시 받는 화면 8을 만들지 못한다.  
장면 붙이기는 Edit의 일이다. ⑥ Voice에서 뒤늦게 문제를 발견하면 한 번 더 해 본 뒤 개발자로 넘어가고, Edit 자체가 실패하면 지금은 일반 멈춤에 그친다.  
화면 9에서 같은 자료로 처음부터 시작하거나 새 Send로 바꾸려면 서버가 현재 작업 한 편을 정해야 한다. 한도 대기와 재시동 뒤에도 같은 기준이 필요하다.

제품 기준판은 로컬 `origin/main` 3072e7e. 화면은 BTSR-RSCH-003 §15–16이 시안 3판보다 앞서며, 작업 중 들어온 §17(7c55ad5)도 개발자 통보에만 반영했다. 파일·상태를 읽어 대조한 모의시험이다. 아래 파일명 앞에는 `app/webapp/`이 붙는다(별도 경로 표기 제외).
