# S14 — 정해진 대로 하지 않았을 때의 예시 (RSCH가 씀 · 2026-11-22 01:38 KST)

근거: 한알 2026-11-22 01:34:40(원문과 시각은 main `owner/utterances/2026-11-22.md`) 「… 여러가지 시나리오로 테스트를 해봅니다. 예를 들어 정해진대로 하지 않았을때 사용자를 위해 ui가 어떤동작을 해야하는지 라던가요. 여러 예시를 만들어서 저에게 보여주세요」

- 쓰는 사람은 **한 사람(미첼)** 이고 아이폰으로 씁니다. 가게 일을 하다가 틈에 누릅니다 — 차례를 건너뛰고, 잘못 누르고, 보내다가 다른 일을 합니다.
- '바라는 모습'은 **RSCH의 안**입니다(확정 아님). 기준은 하나 — **쓰는 사람이 길을 벗어나도 화면이 (가) 지금 무슨 일인지 한 줄로 알려 주고 (나) 다음에 누를 것을 보여 주고 (다) 이미 한 것을 잃지 않게 한다.** 말없이 멈추거나, 눌러도 아무 일이 없거나, 한 것이 사라지면 '안 됨'입니다.
- S14는 예시마다 아이폰 꼴 화면에서 **실제로 그렇게 눌러 보고** 본 것을 적습니다. 예시에 없는 것을 찾으면 E31부터 번호를 더해 적습니다. 바라는 모습이 틀렸다고 보면 그렇게 적습니다.

## 가. 보내기 (Send)

| 번호 | 쓰는 사람이 이렇게 하면 | 화면이 이렇게 해 줘야 (안) |
|---|---|---|
| E1 | 사진을 고르지 않고 Send를 누른다 | 「먼저 사진 · 영상을 골라 주세요」 한 줄 + 고르기 창이 바로 열린다 |
| E2 | 사진만 고르고 Send를 누르지 않은 채 다른 탭(Jobs · Manual)을 보다 돌아온다 | 고른 것이 그대로 남아 있고, 아직 보내지 않았다는 것이 보인다 |
| E3 | 요청 글을 비운 채 보낸다 | 막지 않고 보낸다(요청 글은 없어도 됨). 막는다면 까닭을 한 줄로 |
| E4 | 사진 · 영상이 아닌 것(문서 · 소리 파일)이나 못 쓰는 꼴의 파일을 섞어 고른다 | 못 쓰는 것이 몇 개인지 알려 주고 나머지는 보낸다. 한 편이 그 파일 때문에 말없이 멈추지 않는다 |
| E5 | 같은 사진을 두 번 고르거나, 같은 것을 한 번 더 보낸다 | 두 번 들어가지 않거나, 들어가도 한 편이 망가지지 않는다 |
| E6 | 보내는 중에 화면을 끄거나 다른 앱에 다녀온다 | 돌아오면 이어서 보내거나 「보내다 끊겼어요」 + 「다시 보내기」가 뜬다. 멈춘 채 '보내는 중'으로 남지 않는다 |
| E7 | 보내는 중에 새로 고침 · 뒤로 가기를 한다 | 보내던 것이 있다고 알려 준다. 돌아왔을 때 무엇을 다시 해야 하는지 보인다 |
| E8 | 보내는 중에 「그만 보내기」를 잘못 누른다 | 정말 멈출지 묻고 「계속 보내기」로 돌아갈 수 있다 |
| E9 | 한 편을 만드는 중에 또 보내려 한다 | 왜 안 되는지 한 줄 + 할 수 있는 것(기다리기 · 「처음부터 시작」)이 보인다 |
| E10 | 맥이 꺼져 있거나 와이파이가 끊긴 채 Send를 누른다 | 무엇을 확인하면 되는지 한 줄(맥북 · 와이파이). 고른 것은 남는다 |
| E11 | 보내다 끊겨 「다시 보내기」를 눌렀는데 또 안 된다 | 「사진 · 영상을 다시 골라 주세요」로 이어지고, 다시 고르면 이미 받은 것은 건너뛴다(11-22 00:44에 들어간 고침 — 맨 먼저 볼 것) |
| E12 | 로그인이 풀린 채(오래 열어 둠) 보낸다 | 까닭을 알려 주고, PIN 뒤에 요청 글과 보내던 묶음이 이어진다 |
