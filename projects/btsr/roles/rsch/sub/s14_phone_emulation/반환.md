## 남은 것

- 실제 아이폰에서 화면 잠금·앱 전환, 오래 열어 둔 뒤의 로그인, 사진 보관함 재선택과 이름·크기 변화, 실제 아이폰 사진의 변환·큰 영상 준비 시간을 확인해야 합니다.
- 이 PC의 아이폰 꼴 브라우저(WebKit)에서는 색종이 영상(H.264)이 열리지 않았고, 같은 웹앱의 같은 영상이 기존 크롬에서는 재생됐습니다. 실제 아이폰의 재생·공유 창·사진 앱 저장 결과가 남았습니다.
- 아이폰 한글 자판, 홈 화면 추가, 닫힌 앱의 알림과 매장 보안 주소는 기기에서 확인해야 합니다. 자유 답 입력은 새 접수에서 나오지 않아 예전 형식의 시험 물음으로 동작을 확인했습니다.
- 영상·얼굴의 실제 제작 품질, 맥에서의 편집은 이번 사용 시험의 범위 밖입니다.
