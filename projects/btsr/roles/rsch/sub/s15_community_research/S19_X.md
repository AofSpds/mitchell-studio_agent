## 2. 편집을 무엇으로 하는가

(01:44 적음 — 더 채움)

**한 줄로:** 영어권 만드는 사람들은 2026년에 거의 모두 **'파일 · 코드로 짜고, 한 번 그려 본 뒤, 에이전트가 결과를 다시 보고 고치는'** 쪽으로 갔다. 화면을 대신 눌러 주는 방식(computer use)으로 편집기를 모는 사람의 써 본 글은 이번에 **하나도 못 찾았다** — 쓰는 사람이 없거나, 써 보고 말하지 않을 만큼 안 됐거나다. 영상을 통째로 만들어 주는 모델은 '편집'이 아니라 '조각 만들기'로만 쓴다.

길 다섯 — 저마다:

1. **코드로 영상을 짜기 — Remotion(React) · HyperFrames(HTML).**
   - Remotion은 2026-01-20에 '에이전트 기술'(Agent Skills — 에이전트가 읽는 사용 설명)을 공식으로 냄 → Claude Code · Codex 등이 Remotion 코드를 덜 틀리게 씀. 설명 → 에이전트가 코드 → 미리 보기 → 명령으로 그리기. https://www.remotion.dev/docs/ai/skills · 믿음: 상(공식).
   - **Remotion 허가:** 혼자 · 3명 이하 회사는 상업용도 무료 · 4명부터 돈(자리당 월 25달러 또는 그림 한 번에 0.01달러 · 월 최소 100달러). 5.0에서 조금 바뀐다고 함. https://www.remotion.dev/docs/license · 믿음: 상(공식). → 1인 가게는 무료 쪽.
   - HyperFrames(HeyGen · 2026-04-17 무렵 공개 · Apache-2.0): Remotion을 본떴지만 HTML로 짠다 — "에이전트는 React보다 HTML을 더 잘 쓴다"가 내세우는 까닭. 머리 없는 Chrome으로 한 장씩 찍어 FFmpeg로 묶음 → 같은 입력이면 늘 같은 결과. https://github.com/heygen-com/hyperframes · 믿음: 중(만든 회사의 말 · 반 년 남짓 된 것).
