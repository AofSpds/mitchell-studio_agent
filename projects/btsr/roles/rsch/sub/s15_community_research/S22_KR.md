## 0. 처음부터 만든다면

**한국 커뮤니티(2026년 1 – 8월 글이 대부분)에서 가장 많이 보이는 얼개:**

> **코딩 에이전트(Claude Code가 압도적 · Codex 조금)** + **생성 API 묶음**(그림: Gemini Nano Banana · Imagen / 영상: Veo · Grok Imagine · Kling · Seedance — 흔히 **fal.ai** 한 창구로) + **한국어 TTS**(Typecast · Gemini TTS) + **받아쓰기로 자막 시각**(faster-whisper · Whisper) + **코드로 영상 짜기**(**Remotion**이 대세 · 가벼우면 ffmpeg/MoviePy) — 단계마다 파일을 남기는 고정 흐름.

- GPTers에 이 꼴의 직접 제작기가 2026-01 ~ 08에 열 건 넘게 올라옴(1번 칸). 같은 공부 모임(스터디)에서 나온 글이 많아 **서로 닮았다는 점은 감안**(한 모임의 유행일 수 있음).
- **끝까지 돌아가는 것:** '주제 한 줄 → 20 – 50초 세로 영상(목소리 · 자막)'은 여럿이 실제로 뽑아 냄. **'서버에 올려 사람이 통과/돌려보냄을 누르는 앱' 꼴까지 간 것은 하나**(GPTers 2026-08-10 — Fly.io · R2 · 품질 문 14개). **유튜브 자동 올리기까지 간 것은 둘**(450원 글 · 운세 글). **인스타 자동 올리기까지 간 직접 제작기는 못 찾음.**
- **휴대폰에서 사진 몇 장 + 한 줄을 보내면 돌려주는 꼴**의 한국어 직접 후기는 **찾지 못함**(텔레그램 봇 + n8n으로 '글 → 그림'을 돌려받는 글은 여럿 — 6번 칸).
- **여섯 달 전과 달라진 것(글 날짜로 본 흐름):** ① 2025년 글은 n8n · Make 같은 흐름 도구 + 영상 모델 위주 → 2026년 글은 **코딩 에이전트가 파이프라인 코드를 직접 짜는 쪽**으로 거의 옮겨 감. ② 2026-02 ~ 04에 **Remotion + Claude Code 스킬**이 급히 퍼짐 · 2026-04 GeekNews에 **HyperFrames**(HTML로 영상, Apache 2.0)가 소개됨. ③ 2026 중반 글은 **'만들기'보다 '검사'** — 검수 일곱 가지 · 품질 문 14개 · 만드는 쪽/검사하는 쪽 나누기. ④ 영상 모델은 Veo 한도 문제로 fal.ai의 다른 모델로 갈아타는 글이 늘어남. ⑤ 유튜브가 2025-07 · 2026-07에 '양산형' 수익 제한을 넓힘(8번 칸).
- **'화면을 대신 눌러 주는' 길**은 한국 커뮤니티 직접 제작기에서 **한 건도 보지 못했다.** 편집 프로그램(캡컷) 쪽은 '초안 파일을 직접 써서 사람이 열어 다듬는' 쓰임만 보임.

## 3. 목소리 · 자막 · 음악

**목소리(한국어 TTS)** — 직접 해 본 글에서 쓴 것: **Typecast**(가장 많음 — 한국어가 자연스럽고 단어별 시각을 줌) · **Gemini TTS**(Gemini API 하나로 묶을 때) · Supertonic · gTTS(기계 같아 바꾸려 함) · fal.ai 목소리 모델.
- ElevenLabs는 무료 판 목소리가 영어권뿐이라 뺐다는 직접 글이 있음(GPTers 2026-08-03 글).

- **상업 이용:** 업체 글끼리 엇갈림 — Typecast는 '무료 판은 다운로드 월 5분 · 상업 이용은 유료부터', ElevenLabs도 '상업 이용은 유료부터'라고 Typecast 쪽 글이 씀(https://typecast.ai/kr/learn/professional-tts-cost-commercial-use-2026/ · 2026-09 · **업체 글 = 광고 기운** · 믿음 **하중**). 한 브런치 글은 '무료로 조건 없이 상업 이용이 되는 건 구글 TTS · Qwen3-TTS 정도'(https://brunch.co.kr/@sukistory/140 · 소개 · 믿음 **하**). → **약관을 직접 열어 확인할 일**(RSCH).

**자막** — 거의 모두 **'TTS 소리 → 받아쓰기 모델(Whisper · faster-whisper · Scribe)로 낱말 시각 뽑기 → Remotion이 노래방식으로 그림'**. 내 PC에서 돌리는 faster-whisper가 흔함(소리를 밖으로 안 보냄). 받아쓰기가 이름 · 낱말을 틀리게 듣는 일이 잦음 → 대본을 같이 주면 나아짐 · 자막 자료만 고쳐 다시 그림. 그림 모델이 그림 속 한글을 깨뜨리므로 **글자는 그림에 넣지 말고 자막으로 따로 얹기**.

**사진 → 영상 모델(직접 글에서 쓴 것):** Veo(2 · 3.1 — 8초 토막) · Grok Imagine Video(fal.ai — 10초 상한 · 480p) · Kling · Seedance 2.0(Higgsfield). 한결같은 문제는 **장면마다 인물 · 물건 모습이 달라짐** → 기준 그림을 정해 두고 Nano Banana(참고 그림 최대 14장)로 맞춤 · 'Place this character in …' 같은 지시 꼴. 클리앙 댓글 여럿이 Nano Banana를 권했고 글쓴이가 해 보니 나아졌다고 덧붙임(클리앙 2025-08). **실제 가게 사진을 영상으로 움직인 직접 후기는 못 찾음** — 본 글은 거의 다 지어낸 인물 · 그림체.
- 영상 모델이 **묻지 않은 영어 목소리 · 배경 음악을 넣음**(Veo — GPTers 3주차) · 술병 같은 물건이 **안전 거름에 걸림**.
- **AI 배경 지우기 사고** — 배경은 두고 인물의 옷만 지운 장면(GPTers 2026-03-29 글이 일부러 소재로 씀). 자동 지우기는 결과를 사람이 봐야 함.

**사진 다듬기:**
- 남의 영상에 박힌 자막 자리만 찾아 흐리게(GPTers 2026-08-03 — 자리를 잘못 찾거나 범위가 넓어 세 번 다시).
- **말로 시키는 사진 편집(Nano Banana 바탕의 웹 서비스)** — GPTers 'Imgful AI 사용 후기' https://www.gpters.org/hello/post/photo-editor-just-words-IxU6RqDBlxBS8M0 · 2026-02-07 · **후기 꼴이지만 광고 기운이 셈**(결과물 · 실패 없음 · '무료 체험' 되풀이) · 믿음 **하**. 낯선 사람 지우기 · 배경 바꾸기 · 조명 · 색 보정을 말로 · 8 – 15초 · 상업 이용 가능(업체 말). → 쓸 만한 것은 '**Nano Banana류 모델에 말로 시키면 배경 · 물건 지우기가 된다**'는 방향뿐, 수치는 믿지 않음.

- 이름 가리기(글자) — 손님 후기 38건을 릴스로 만들며 이름 가운데 글자를 O로 바꿈(아래 6번 칸 Metricool 글).

## 5. 에이전트의 얼개

본 직접 글들에서 세 꼴이 보인다.
1. **코딩 에이전트 한 세션이 단계마다 사람 지시를 받아 진행**(Claude Code · Codex) — 가장 흔한 시작점. 만들기는 빠르나 '한 번 만들어 봄'에서 멈추는 글이 많다.
2. **단계를 스킬 · 하위 에이전트로 나눈 고정 흐름** — 역할별 일곱 단계(3주차 글) · 스킬 넷을 갈아 끼움(오!사이언스 글) · 단계별 폴더. '한 단계만 고쳐도 전체를 다시 안 돌린다'는 장점이 되풀이됨.
3. **'고정 코드 + AI 스킬'을 나눈 서버 앱** — GPTers 2026-08-10 글: 로그인 · 상태 · 저장 · 실패 처리 · 품질 검사는 **보통 코드**로, 대본 · 번역 · 목소리 · 화면만 AI로. 품질 문 14개 + 사람이 통과/돌려보냄.

되풀이되는 배움(직접 글 여럿에서):
- **AI의 '다 했다'를 믿지 말 것** — 소리가 빈 채로 '완료' 보고(2026-08-03 글). → **만드는 쪽과 검사하는 쪽을 나누고**, 길이 · 소리 · 자막 · 장면 넘김을 자동으로 잰다(검수 일곱 가지 · 품질 문 14개 · 미리보기와 최종본 길이 맞대기).
- **사람이 보는 자리:** 처음(설정 · 대본 확인)과 끝(완성본 재생 · 통과/돌려보냄). 클리앙 댓글: 검수를 줄이면 품질 · 믿음이 떨어진다.
- **다시 하기:** '이미 만든 파일은 건너뛰기'(잔액 바닥 · 한도 소진 뒤 이어 가기) · 실패한 장면만 다시 만들기 · 올리기 실패면 다시.
- **갈아 끼우기:** 영상 모델 한도가 바닥나면 다른 모델로(Veo → Grok Imagine) · 모델이 없어지면(Imagen 3 → 404) 목록을 물어 바꿈 → **모델 이름을 한 곳에 두고 고정**(코드 안에서 몰래 바뀐 번역 모델 사례).
- **기록:** 결과 폴더에 영상 · 올릴 글 · 검수 기록 · 넣은 것의 사본을 같이 둬 다시 만들 수 있게(2026-08-03 글). 돌리기 전 점검 스크립트(preflight/doctor).
- 값 아끼기: 단순한 일은 값싼 모델, 설계는 중간 모델(2026-08-03 글).

## 6. 휴대폰에서 쓰는 꼴

**한국 커뮤니티에서 '휴대폰으로 사진을 보내면 영상이 돌아오는' 직접 제작기는 찾지 못했다.** 가까운 조각들:
- **텔레그램 봇 + n8n** — GPTers에 '텔레그램으로 그림 지시문을 보내면 만든 그림을 텔레그램으로 돌려받기'(https://www.gpters.org/nocode/post/n8n-automation-sending-image-tSbDLJhwchN9gIF — n8n을 내 PC에 · Gemini · Telegram Bot API) · '사진을 보내면 글을 읽어 목소리 파일로 돌려주기'(https://www.gpters.org/nocode/post/telegram-bot-completes-text-xLCGITe03Dkrijg) 같은 글이 많음(검색 요약으로 봄 · 원문 안 엶 · 믿음 **중하**). 공통 불평: 텔레그램 API 설정이 번거로움 · n8n이 메시지 끝에 문구를 붙이는 것을 꺼야 함. **휴대폰 쪽 앱을 따로 만들지 않고 메신저 봇을 입구로 쓰는 것**이 한국 취미 개발자들의 흔한 꼴.
- **서버 자리:** 내 PC(맥 · 윈도) 위의 Claude Code가 대부분. 서버에 올린 것은 Fly.io(웹 · 그리는 일꾼 따로) + R2(파일) 하나(GPTers 2026-08-10). 이 글에서 **웹 서버와 그리는 서버의 판이 어긋나 자막 줄 수가 달라짐** — 그리는 환경을 하나로 고정할 일. Remotion은 '클라우드 서비스가 아니라 내 컴퓨터 자원을 쓰는 엔진'이고, 여럿을 한꺼번에 그리려면 AWS Lambda(돈 듦)라는 소개 글(검색 요약 · 믿음 **중**). Remotion을 윈도에서 돌릴 때 띄어쓰기 · 한글 폴더 이름 · Remotion이 내려받는 크롬 실패 같은 오류 후기가 있음(검색 요약).
- **유튜브 올리기:** YouTube Data API + OAuth로 자동 올리기를 한 직접 글 둘. 권한 범위를 '올리기 전용'으로 하면 공개 설정을 못 바꿈 · 처음엔 비공개로 올라감(GPTers 450원 글) · 실패하면 다시 올리기(운세 글).
- **인스타 올리기:** 공식 API로 직접 올린 한국어 제작기는 못 찾음. 가장 가까운 것: GPTers '수강생 후기 → 인스타 릴스 자동화' https://www.gpters.org/media/post/jeongseongseureon-sugangsaeng-hugi-inseutageuraem-reels-jadonghwa-ms6HKEfMKkKsTD9 · **2024-06-16(오래됨)** · **직접 해 봄**(릴스 올라간 것 확인) · 믿음 **중** — 구글폼 → 시트 → Canva 대량 제작(CSV) + moviepy → **Metricool(예약 올리기 서비스)의 Autolist에 CSV를 올려 매일 정한 시각에 예약**. 공식 API를 직접 부르지 않고 **남의 예약 서비스에 맡김**. 틱톡 인기곡 10초를 잘라 씀(권리 검토 없음 — 8번 칸의 '하지 말 것'). 검색 요약으로 본 것(공식 개발 문서 · 안내 글): **프로페셔널(비즈니스 · 크리에이터) 계정이어야 API로 릴스를 올릴 수 있음** · 영상은 '먼저 그릇(컨테이너)을 만들고 → 따로 올리는 주소로 올리고 → 게시' 세 걸음 · 앱 심사 · 토큰 갱신이 걸림 · 앱당 시간당 200번 부름. 한국 개발자의 '릴스는 사진이 아니었다 — 쇼츠를 인스타 · 페북에 API로 뿌리며 부딪힌 것들'(https://wikidocs.net/blog/@hyeong/24085/)은 **403으로 못 엶**(못 본 것).
- **알림 · 확인:** 사람이 '통과 / 돌려보냄'을 누르는 화면을 웹으로 둔 것이 하나(2026-08-10). n8n 글은 '단계마다 텔레그램으로 확인받기'를 다음 할 일로 적음.
