## 4. 엇갈림

### ① 아스트라 글과 오퍼스 글 사이

- **표본·접근 차이:** X는 S15:9,78,82의 임베드 열람과 S19:229,242의 대체 조사다. Reddit은 S16 원문과 S20의 원문 차단·공개 코드 대조가 다르다(Q13·Q15). 중국은 S17:31,46,76,80의 일부 본문 열람과 S21:250–251의 막힘, 한국은 S18:52의 디시 후기와 S22:194의 미발견을 구분한다. 서로 못 찾은 것을 모두 없다고 합치지 않는다.
- **성공과 검색 공백:** S15:30,65의 네 도구 세로 완성 실험은 S19:57,233의 미발견을 메운다. S17:31의 GUI 여섯 편은 S21:71–81의 사람 개입 약점과 양립한다. S15:51,53·S16:55의 다중 에이전트 사례와 S19:145·S20:90의 드묾/미발견도 표본이 다르다(X19·C04·X59·Q48).
- **코드로 좁힌 Reddit 주장:** S16:25의 같은 대화 반환은 S20:162의 고정 수신처로 고쳐졌다. Invokard ‘작업 전후’는 S20:161에서 미확인이나 34클립 핵심은 확인됐다. OpenFilm의 XML·CapCut 내보내기는 S16:34 설명과 S20:163의 미확인이지 기능 부재의 증명은 아니다(Q25·Q15·QX08).
- **입력 기능의 실제 충돌:** S20:19는 MoneyPrinterTurbo·short-video-maker를 ‘내 소재 없음/약함’으로 묶지만 S21:54는 MoneyPrinterTurbo 자기 파일을 명시한다. 확인한 S20:42의 직접 불가 조건은 short-video-maker다. MoneyPrinterTurbo는 입력 있음으로 고치고 품질 검증 여부를 따로 남긴다(Q45↔C41; 이번에 해당 줄만 직접 확인).
- **조건 추가와 약관 미확인:** Supertonic S16:41의 허가 표시에는 S20:74,164의 흉내 금지·표시를 더한다. CML·Pexels의 S20:155–156 미열람은 S16의 반증이 아니다. edge-tts S17:38,40의 사용 사례·상업 근거 미확인은 S21:107,243의 우려와 정면 대립하지 않는다(Q33·QX02·QX03·C31).
- **한국·중국의 서로 다른 단위:** Typecast S18:44,79와 S22:113,201은 API/웹 상품 차이일 수 있다. 상품 쇼츠 컷 간격 S18:26,35의 0.5초와 S22:66–70의 0.1–0.3초는 원문 동일 여부부터 미검증이다. S17:69의 조건부 공식 가격은 S21:224,252의 값표 미열람을 메우며, S17:59의 飞书 연결 미완을 다른 사례 성공으로 덮지 않는다.

### ② 지역 사이

- **촬영본/생성·편집기:** X·Reddit·중국의 촬영본 권고와 한국 S22:26,36–90의 생성 위주 완주를 같은 입력으로 세지 않는다. GUI는 다른 지역의 미발견보다 중국의 특정 완성 기록이 우선하며, 어떤 지역도 이로써 무인 반복 성공률이 확인된 것은 아니다(K02·C04).
- **도구·앞문:** 한국 S18:13은 고른 네 건 중 FFmpeg 셋, S22:26,98은 Remotion이 흔하다는 표본이다. X의 한 번 비교로 세계 최저가를 정할 수 없다. 중국 飞书, 해외 텔레그램, 한국 웹/텔레그램은 발견 사례이며 나라별 점유율이 아니다(K45·X19·C26·K12).
- **게시·권리·검토:** 한국 자동/예약과 수동 권고, TikTok 공개 Direct Post와 다른 게시 경로, 중국판/국제판 소재 조건을 분리한다. 무료 전체 비상업·사람 두 번이라는 공통 조건은 성립하지 않는다(K07·X09·C33·Q32·C10).
- **돈·하루량:** 모델 정가 환산·부분 API값·그림 생성 포함 제작자 계산·생성 시도 횟수·완성본 수가 다르다. 지역별 수치를 한 공통 단가나 폐기율로 합칠 수 없다(X12·Q52·K62·C15·X64).

### ③ 바탕 글과 RSCH 원문 재확인(종합본 2-1) 사이
