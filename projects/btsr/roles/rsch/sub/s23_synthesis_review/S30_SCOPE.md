**길 2를 고르면 달라지는 것 — 다섯 줄 안**

- 정해 둔 순서의 구현보다 에이전트에 도구를 붙여 말로 고치는 흐름이 중심이 된다. 사람의 개입·수정 기록과 구독 사용량을 첫 판 범위에 넣는다(읽은 이의 판단; 종합:148–152).
- 편집표/굽기 검사에 더해 같은 요청 반복 때의 장면·문구 차이와 Windows 실행을 먼저 확인한다. ‘짓는 품이 적음’을 실측된 우열로 보지 않는다(읽은 이의 판단; 종합:150–151; S24:185).
- 작업 격리·유료 호출 제한·완성 파일 검사·폰 반환은 그대로 필요한 후보이며, 에이전트가 편집표만 쓰면 길 1 안의 부품 사용이다(읽은 이의 판단; 종합:152; S24:165; S26:166).

**길 3을 고르면 달라지는 것 — 다섯 줄 안**

- 첫 결과를 ‘초안만’과 ‘편집기가 내보낸 MP4’ 중에서 가르고, 초안 만들기→열기→수정→내보내기를 따로 확인한다(읽은 이의 판단; 종합:156–158; S25:165).
- 중국판/국제판·앱 판·운영체제·VIP·화면 점유·사람이 마무리하는 품이 범위에 들어온다. 지원 판 충돌은 미확인으로 둔다(읽은 이의 판단; S25:165·175; 종합:159).
- ‘완성 사례 없음’으로 제외하지 않는다. 여섯 편 기록은 있으나 무인 정도·반복률은 미확인이고, 양식·글꼴 누락과 음악 허용 게시처도 확인한다(읽은 이의 판단; S25:146·148·176; S23:162).

## 2. 기술 시험 후보

번호는 작은 공통 검사부터 연결 시험으로 가는 우선순위다. 선택한 길·첫 결과에 필요한 것만 실행 후보로 남긴다. 설치·키·돈의 준비 분류는 실행 지시가 아니며, 이번 창에서는 어느 시험도 하지 않는다. 시험 코드·결과의 자리는 후속 의뢰에서 정한다(S27:19·144).
모든 입력은 직접 만든 것 또는 재사용이 허용된 공개 소재만 쓴다. 손님·남의 얼굴이 든 사진/영상과 실존 인물 기반 얼굴 합성은 제외한다. 얼굴 시험은 비실존 합성 소재가 없으면 보류한다(S27:17·101).
아래 통과선·시간은 **읽은 이의 판단**이다. S27의 수치는 계획값을 이어받았고, 대조 글에서 더한 시험도 실측값이 아니다. 가입·허락·소재 확보 대기는 시간 어림에서 뺀다(S27:7·143).

### 키 · 돈이 있어야 되는 것

키·계정만 필요한 후보와 과금 후보가 섞여 있다. 각각 필요한 조건을 적었으며 모두 유료라는 뜻은 아니다. 미기재 비용은 0원으로 채우지 않는다. 키 값은 문서에 적지 않는다(S23:175; S27:112; S28:76).

## 4. 한알께 여쭐 것

질문안만 적는다. 지금 선택을 요청하거나 답을 확정한 것이 아니다. 보기는 **읽은 이의 판단**이며 여러 개가 필요한 질문은 함께 고를 수 있다(S28:64–74).

**지금 여쭐 것 — 두 가지**

1. 어느 길로 첫 설계안을 쓸까요? **1 정해 둔 차례+편집표 / 2 코딩 에이전트에게 통째로 / 3 편집 프로그램을 거침**(S28:66; 종합:201).

**나중에 여쭐 것 — 일곱 가지**

3. 설계 때, 직접 확인하고 고칠 범위는 어디까지 둘까요? **1 계획·완성본 확인 / 2 문구·자막도 수정 / 3 장면·편집도 수정**, 편당 가능한 시간도 적어 주세요(S28:68).
