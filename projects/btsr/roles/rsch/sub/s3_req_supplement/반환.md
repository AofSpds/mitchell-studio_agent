## 4. 남은 것

- 한알께 여쭐 것은 규격 밖 승인본의 납품 가능 여부, 의도적으로 쓰지 않는 AI 얼굴의 누락 안내 여부, 오류 때 판단을 먼저 요청하는 쪽, 1차의 중간 산출물 범위다. 권고와 근거는 보완안 마1~마4에 있다.
- 지정된 `gh api` 실행은 명령 미발견과 설치 패키지 폴더 접근 거부로 막혔다. 제품 Git HEAD 조회는 소유권 검사로 막혔다. 제품 파일 본문은 로컬에서 읽었다. 실기 시험은 수행하지 않았다.
- **커밋·push 막힘.** 두 파일을 이름으로 지정한 `git add --`에서 `.git/index.lock` 생성 권한이 거부되었다(`Permission denied`). 두 파일은 SUB 칸에 남아 있고 이번 산출물의 커밋 번호는 없다. 패킷에 따라 이 두 파일의 커밋과 push는 PRIMARY에게 반환한다.
