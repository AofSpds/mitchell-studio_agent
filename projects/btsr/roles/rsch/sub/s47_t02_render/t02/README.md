## 왜 멈췄는가

처음 요청한 주소는 `https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip.sha256`이다.
서버가 다른 주소로 이동시키는 HTTP 303을 반환했다.
`OPEN_PACKET.md`의 “웹은 위 두 주소만”과 “막히면 멈추고 보고”에 따라 이동을 따르지 않았다.
다른 주소 접속·다른 다운로드 도구·재시도는 하지 않았다.
ZIP 요청도 시작하지 않았다. 검사값을 얻지 못했으므로 압축 해제와 실행은 하지 않았다.
스크립트의 압축 해제·버전 확인 부분은 작성만 했고 실행 검증하지 못했다.

## 하지 않은 것

FFmpeg 버전·drawtext·libfreetype 확인, 시험 소재 넷 생성, 소재 앞뒤 SHA-256 측정,
편집표 작성, 렌더 두 차례, ffprobe 검사, 오류 편집표 두 건 거절 시험, 장면 PNG 추출을 못 했다.
공개·실측 ZIP SHA-256 값은 모두 미취득이다.
한글 자막의 시각 판정은 RSCH 담당이며 이번에는 판정할 영상·그림이 없다.
휴대폰·실제 촬영본·편집 앱·품질 판정은 원래 범위 밖이다.
PATH·레지스트리·환경 변수·시스템 설정을 바꾸지 않았고, 설치·커밋·push를 하지 않았다.
사람·얼굴·손님 자료·다른 사진·키·비밀을 사용하거나 저장하지 않았다.
