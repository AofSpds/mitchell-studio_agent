# T02b 어절 줄바꿈과 자막 안전 자리

상태: 2026-11-28 19:59:04 KST 완료. 최종 단계 검사 통과 121 / 실패 0; 이전 임시 검사 25개·권한 중단 1건 별도 보존.
원래 T02 복사본을 이 폴더에서만 고쳤다. T02 코드와 work/는 읽기만 한다.

## 실행

Node 내장 모듈만 사용한다. 설치·웹·다운로드·진행판·커밋·push는 없다.
이 폴더의 명령 순서: node plan.mjs → node prepare.mjs → node preflight.mjs →
node render.mjs → node verify.mjs → node report.mjs.
prepare는 새 work_t02b/를 단독 생성한다. 기존 출력이 있으면 재실행은 중단한다.
권한 거부는 중단·기록한다. work_t02b 생성 EPERM 뒤 RSCH의 명시 지시로 같은 명령을 정식 권한 올림해 허용받았다.
삭제 코드가 없다. FFmpeg·ffprobe는 승인된 기존 bin/ 절대 경로로만 실행한다.
FFmpeg 호출은 shell:false, 인수 배열, UTF-8 자막 파일이며 텍스트 확장은 끈다.

## 줄바꿈 방식과 한계

captions.mjs가 C:/Windows/Fonts/malgun.ttf의 cmap·hmtx·glyf·head·hhea를 직접 읽는다.
48px 크기의 실제 advance와 글자 잉크 경계로 너비를 추정한다. 한글·영문·숫자 폭이 다르다.
글자별 advance를 올림하고 좌우 2px 여유를 더하므로 글자 수 방식보다 가깝고 약간 넉넉하다.
단어 간격은 한 칸으로 정리하고 명시한 줄바꿈은 유지한다. 원문은 편집표·results.txt에 보존한다.
온전한 어절이 한 줄보다 길 때만 그 어절을 코드포인트 단위로 나눈다.
그때 원 어절·분할 조각·너비·까닭을 forcedBreaks로 기록한다.
최대 5줄이다. S48 폭에서도 원래 T02 긴 자막을 보존하기 위한 시험 한도이며 게시 규칙은 아니다.
줄 수 초과는 CAPTION_LINE_LIMIT으로 파일 생성·FFmpeg·ffprobe 전에 거절한다.
폰트 커닝·GPOS·힌팅을 완전히 구현하지 않는다. text_shaping=0이며 복합 문자 조형은 범위 밖이다.
조합 부호·결합 문자·분해 한글·없는 글리프는 사전 거절한다. 완성형 한글과 영문·숫자를 시험한다.
최종 drawtext 상자는 별도 흑백 래스터로 실측해 계산 상자·안전 영역 안에 들어가는지도 검사한다.
실측 검사는 이 시험 문장에 대한 확인이며 모든 언어의 정확한 조판을 보장하지 않는다.

## 자막 안전 자리

output.captionSafeArea = { top:430, bottom:720, left:100, right:200 } (픽셀).
1080×1920에서 x=100–880, y=430–1200. 검은 배경과 20px 안쪽 여백을 포함한다.
값 근거: sub/s48_caption_safe_area/S48_SAFE_AREA.md 끝 표 · 임시 공통 영역(읽은 이의 판단)
RSCH가 전달한 값으로 적용했다. 플랫폼 전체의 공식 공통 규격이라고 주장하지 않는다.
글자 가용 폭은 740px, 중심 x=490. 상자 아래 끝은 y=1200, 글자 아래는 y=1180이다.
줄바꿈을 먼저 계산하고 글꼴 최대 높이로 상자를 보수적으로 계산해 네 여백과 비교한다.
폭은 여백에 맞춰 다시 접으며, 높이·줄 수가 넘치면 굽기 전에 거절한다.
첫 임시 T02 자리 검사는 results.txt 앞부분에 남겼다. S48 적용 전에 구운 영상은 없다.
