## 넣지 않은 것과 까닭

- 미P4는 S44 공개 코드 대조를 RSCH가 수용했다. 장면을 하나 고친 뒤 어느 원본·전사를 실제로 재사용하는지는 실행 시험 몫이다.
- 공식 숫자 하나, 특정 판의 파일 유무, 단일 약관 주소 확인은 Astra 보조 몫이다. 실제 청구액과 우리 작업 시간은 직접 측정할 값이다.
- T02의 동일 입력 출력과 T02b의 어절 줄바꿈은 이 컴퓨터에서 확인했다. 실제 폰 조작, 편집기별 왕복, 자막 가독성의 최종 판정은 직접 시험에 남긴다.
- 컴퓨터·휴대폰 양쪽 편집은 결정됐다. 3D 등 여러 영상 작업은 나중 범위다. 이 컴퓨터의 성능, 실제 폰의 복구 성공 여부, 3D 장면의 출력 품질은 직접 시험에 남긴다. 열리지 않은 주소 하나를 다시 확인하는 일도 따로 세지 않았다.
- 내부 기록 조회, 실제 사람 정보·비밀 값 또는 봉인·평가 자료가 필요한 물음은 제외했다.
